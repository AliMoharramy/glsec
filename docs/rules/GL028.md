# GL028 — `artifacts: untracked: true` without sensitive-file exclusions

**Severity:** `warn`  
**OWASP:** [CICD-SEC-7 – Insecure System Configuration](https://owasp.org/www-project-top-10-ci-cd-security-risks/CICD-SEC-07-Insecure-System-Configuration)

## What glsec checks

glsec flags jobs that set `artifacts: untracked: true` unless an `artifacts: exclude:` entry matches a sensitive-file pattern. A `paths:` list does not restrict untracked files — GitLab adds all untracked files in addition to the listed paths. Without a matching exclusion, GitLab archives every file that git does not track — including `.env` files, generated private keys, temporary credential files, `.git/config` with embedded tokens, and build outputs containing secrets. These artifacts are stored by GitLab and downloadable by anyone with project access.

The finding is suppressed only when at least one `exclude:` entry matches a sensitive-file pattern, such as `**/.env`, `**/*.key`, `**/*.pem`, or `**/credentials*`. Excluding unrelated files such as `__pycache__` or `*.tmp` does not address this risk. When possible, remove `untracked: true` and list only the required files under `paths:` instead.

Entries ending in `/`, such as `secrets/`, name directories. GitLab does not recursively exclude their contents, so these entries do not suppress the finding.

Complements GL005, which flags sensitive file patterns already present in `artifacts: paths:`.

## Trigger example

```yaml
build:
  script:
    - make build
  artifacts:
    untracked: true   # archives everything git doesn't track, including .env, *.key, etc.
```

## Safe alternatives

**Restrict to explicit paths (preferred):**

```yaml
build:
  artifacts:
    paths:
      - dist/
      - build/
    expire_in: 1 week
  script:
    - ./build.sh
```

**If `untracked: true` is required, exclude sensitive files explicitly:**

```yaml
build:
  artifacts:
    untracked: true
    exclude:
      - "**/.env"
      - "**/*.key"
      - "**/*.pem"
      - "**/credentials*"
  script:
    - ./build.sh
```
